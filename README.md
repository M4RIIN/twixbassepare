# Marsollier Video

Site vitrine statique en React. Les rubriques « Motion design », « Contenus de marque » et « Créatif » mènent aux projets correspondants sur l’accueil.

## Développement

Avec Node.js 22.12 ou supérieur, depuis ce dossier :

```sh
npm ci
npm run dev
```

## Version statique

```sh
npm run build
npm run preview
```

Publier le contenu de `dist/` sur un hébergement statique. L’archive de livraison contient déjà ce dossier compilé.

## Contenus

Les projets, références et coordonnées sont dans `src/content.js`. Les vignettes, le portrait, le monogramme et l’image d’ouverture ont été extraits de la maquette fournie. Les fichiers vidéo et les témoignages définitifs pourront être ajoutés à réception. Les licences des polices sont dans `public/assets/licences/`.
